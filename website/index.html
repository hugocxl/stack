@hugocxl/sounds is a free set of {{count}} tactile sounds for buttons, toggles, keys, menus and status. Every one is synthesized live with Web Audio, so there are no files to load and nothing plays the same way twice.

A click and a body

Most sounds layer a bright burst of filtered noise over a short tone that falls in pitch. The noise is the plastic, the tone is the mass, and together they read as a real key going down.

Down and up

A press and its release are different sounds. Going down is lower and louder, coming up is shorter and brighter, and a primary button lands a little heavier than the rest.

Works where you build

Use it from plain JavaScript, React or any framework, and map the same haptics you know from iOS. The docs show how to wire an interface in a few lines.

npm install @hugocxl/sounds

Free to use

The sounds and the code are free for personal and commercial work under the MIT license. The docs credit where they started.
