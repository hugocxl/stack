# Working on @hugocxl/components

The design system as components. One platform-neutral **recipe** per component, built for
React (the npm package `@hugocxl/components`) and SwiftUI (the `Components` library of the
`hugocxlStack` Swift package). React Native comes later from the same recipes.

## Layout

- `recipes/<name>.json`: the source of truth. Purpose, anatomy, options, states, the
  design-system tokens it uses, rules and accessibility, and the name it has on each platform
  (`null` where it does not exist).
- `packages/components/`: the npm package. `src/react/` (TypeScript, built to `dist/react`),
  `src/components.css` (every value a `--ds-*` token). `dist/styles.css` adds the
  design-system fonts and tokens; `dist/recipes.json` ships the recipes.
- `Sources/Components/`: the Swift library, declared in the root `Package.swift`.
  `Tokens.swift` and `Resources/Fonts/` are generated by `pnpm run sync` from the published
  `@hugocxl/design-system`; never edit them by hand. `Gallery.swift` has a specimen per recipe.
- `tests/`: React render tests (`*.test.mjs`) and `ComponentsTests` (Swift).
- `website/`: hugocxl.github.io/stack/components, a React app made with the package itself.
  `website/swift/` holds the SwiftUI captures, rendered from the gallery by `pnpm run snapshots`.

## Adding or changing a component

1. Write or change the recipe.
2. Build it in React (`src/react`, exported from `index.ts`, styles in `components.css`) and in
   Swift (`Sources/Components`, named `DS<Name>`), or set the platform to `null`.
3. Add a specimen to `Gallery.swift` and examples (with the Swift snippet) to
   `website/examples.tsx`, then run `pnpm run snapshots`.
4. `pnpm test` and `pnpm run test:swift`. `scripts/check-recipes.mjs` fails when a recipe and
   its implementations, gallery, captures or examples disagree.

## Rules

- Only design-system tokens: no raw colors, sizes or radii in CSS or Swift.
- Icons come from `@hugocxl/icons` (React) and `Icons` (Swift); figures from `@hugocxl/vectors`.
- The package depends on the published `@hugocxl/design-system` and `@hugocxl/icons`, never
  the workspace copies.

## Check before you commit

```sh
pnpm install                 # at the repository root
cd components
pnpm test                    # build, sync and recipe checks, typecheck, React tests
pnpm run test:swift          # Swift tests (macOS)
pnpm run snapshots           # after changing a Swift specimen
pnpm run dev                 # the website at http://localhost:4322/
```

## Releases

A push to `main` that changes `components/` and passes `.github/workflows/components.yml`
publishes `@hugocxl/components` and a GitHub release tagged `components-v<version>`. Swift
changes also release the `hugocxlStack` package through `swift.yml`.
