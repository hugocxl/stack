Icons is a free family of {{count}} rounded icons for websites and apps. They share one set of shapes and proportions, so a toolbar, a settings screen and an empty state all look like they belong together.

Three styles, one family

Duotone adds a quiet second tone for depth. Solid brings emphasis, and Stroke keeps things light. {{full}} icons come in all three styles. The {{brands}} brand marks keep their original look in Duotone.

Find the one you need

Search by name or look through {{category-count}} categories, from navigation and files to weather, money and fitness. Preview any icon at a few sizes, then copy it or download it.

Works where you build

Use the same icons as plain SVG files, in JavaScript and React, in React Native and Expo, or in Swift on Apple platforms. The docs show how to add them in a few lines.

Free to use

The original artwork is free for personal and commercial work under the MIT license. Adapted artwork and brand marks keep their own licenses, as the docs explain.
