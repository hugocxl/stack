Set up a project for agents

Each library ships its own agent skill inside its npm package, so the instructions always match the version a project has installed. @hugocxl/ai adds what no single library can say: which library covers which need, how colors and sounds pair with the design system, and the rules every project shares.

npm install @hugocxl/design-system @hugocxl/icons @hugocxl/vectors @hugocxl/sounds
npx @hugocxl/ai init

init writes a managed section in AGENTS.md for Codex, Cursor, Copilot, Gemini and most other agents, a CLAUDE.md for Claude Code, and the skills in .agents/skills/ and .claude/skills/. Commit them, and run npx @hugocxl/ai sync after installing or upgrading a library.

Check what they build

The check reads the catalogs of the installed libraries and reports icons, vectors and sounds that do not exist, other icon libraries and raw colors. It exits with 1 on errors, so it works in CI and in an agent's own loop.

npx @hugocxl/ai check

Every Claude Code session

To have the skills in every session without setting up each project, add the stack as a Claude Code plugin marketplace. The stack plugin installs the design-system, icons, vectors and sounds plugins with it, each from its latest npm release.

claude plugin marketplace add hugocxl/stack
claude plugin install stack@hugocxl

Free and open source

All of it lives in one repository and is free to use under the MIT license. Each library keeps its own docs and releases, linked from the navigation at the top of every page.
